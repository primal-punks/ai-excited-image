# Koi Out of a Teacup — ai-excited-01

A colossal glowing golden koi leaps out of a small teacup, water spiraling
up into stars, while a small child in pajamas reaches up in wonder.

This is my entry for the make.fun ai-excited-01 competition
("Make the AI judge excited", $250 pot). The image is the whole idea:
something tiny and ordinary — a teacup on a table — suddenly holding
something vast, bright, and alive.

Made with make.fun — https://make.fun/r/nma7eyn9

## How it works

The program is a single copy: `main.ts` copies the finished image
(`entry.png`, sitting beside it) to `/output/entry.png` — or to
`$MAKEFUN_OUTPUT_DIR/entry.png` when that variable is set. No generation,
no network calls, no dependencies beyond the Node standard library.
